# Partelier FIT identity

The user selected **01 / FIT** on2026-11-03, then requested a thinner upper bar
and a compact header. [fit-concept.png](fit-concept.png) is the selected imagegen
proposal, copied unchanged from the generated preview. It is a design reference,
not a runtime bitmap.

The app uses [brand-fit.svg](../../Partelier/partelier/ui/brand-fit.svg), a small
two-path vector adaptation with a thinner T cap and a filleted U base. Pale
blue/white and muted blue suit the existing graphite header. The wordmark stays
native text for clarity at the compact header size. See
[the implementation notes](../compact-ui.md) for dimensions and checks.
